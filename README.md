
# 🥗 NutriPlan — Smart Nutrition Tracker

A nutrition tracking web application built as part of my **JavaScript Exam at Route Academy**.

NutriPlan helps users explore meals, discover food products, and track their daily nutritional intake through an interactive interface.

## 📌 Project Overview

NutriPlan is designed to make daily nutrition tracking easier by combining meal discovery, nutritional information, and a personal food diary in one application.

Users can explore meals, view detailed recipes, search for food products, and track their daily calories and macronutrients.

## ✨ Core Features

### 🏠 Home Page
- Display up to 25 meals.
- Filter meals by category.
- Filter meals by area.
- Explore available meals.

### 🍽️ Meal Details
- View meal information.
- Explore ingredients and measurements.
- Read preparation instructions.
- Watch cooking videos.
- View nutritional information.
- Add meals to the daily Food Log.

### 📊 Food Log
- Track daily food consumption.
- Save meals and products using LocalStorage.
- Calculate total calories.
- Track protein, carbohydrates, and fats.
- Monitor daily nutritional goals.
- Manage logged food entries.

### 🔎 Product Scanner
- Search for food products by name.
- Search using product barcodes.
- View product nutritional information.
- Add products to the Food Log.
